# Vox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a voice-first collaborative analytics canvas where users speak queries, an agent renders charts live, and both agent and user read/write the same CanvasState via shared Agent-Native actions.

**Architecture:** Next.js 14 App Router frontend with a single canvas page; Agent-Native `defineAction` actions serve as the shared contract between React UI, the agent loop, and external webhooks. CanvasState lives in a Zustand store on the client and is persisted per-session in a Vercel KV store; every mutation goes through a `defineAction` so the agent and user call identical endpoints.

**Tech Stack:** Next.js 14, @agent-native/core/action, Recharts, react-leaflet (choropleth), Zustand, Web Speech API, PapaParse (CSV), pg (PostgreSQL), Tailwind CSS, Vercel + Vercel KV

**Spec:** No external spec file — requirements captured in this plan from conversation context (2026-11-08).

---

## Global Constraints

- Node >= 20, Next.js 14.x (App Router), TypeScript strict mode
- @agent-native/core/action must be used for ALL state mutations — no direct store writes from UI bypassing actions
- Web Speech API only for voice (no paid STT service)
- Deploy target: Vercel (no Docker, no Railway)
- Chart library: Recharts only (no Chart.js, no Plotly)
- Map: react-leaflet + leaflet (choropleth via GeoJSON)
- CSV parser: papaparse
- PostgreSQL client: pg (no ORM)
- No auth for MVP — single shared canvas per deployment
- Deadline: Nov 9 2026

---

## Review Focus

1. **Empty CSV / malformed headers** — `connectDataSource` must return a typed error, not throw; UI shows inline error on the data source panel
2. **PostgreSQL connection failure mid-query** — `runQuery` must catch pg errors and return `{ error: string }` so agent can surface them; never crash the canvas
3. **Web Speech API unsupported browser** — `useVoice` must degrade to a text input fallback with zero JS errors
4. **Agent produces chart type not in allowed set** — `addChart` schema uses a discriminated union; unknown `chartType` values must be rejected at the action boundary, not at render time
5. **Concurrent agent + user mutation on same chart** — `CanvasState.revision` must be checked on every write action; stale-revision writes return `409` so the agent re-reads before retrying
